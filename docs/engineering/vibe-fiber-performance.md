# Vibe Fiber 性能审查（2026-10-07）

基线：GitHub `main` 提交 `5e73b5552e9737678e88546e848b75a1d4e06475`。先通过 GitHub API 核对远端分支与本地提交一致，并比对 renderer.js blob。此轮只修改 Vibe Fiber；不提交既有 Effecter 与应急状态改动。

## 改动

- 文字掩码按实际绘制范围读取像素和采样，保留原来的网格与字形归属；为空白文本跳过像素读取。包含混合图案、文本片段及越界裁剪，字体没有有效边界指标时回退到完整画布。
- 同一次布局缓存文本宽度和字形指标；字号变化清除宽度缓存，保留整段前缀的原生字距与连字测量。
- 每针绘制复用已经生成的覆盖贴图，移除重复材质与相邻针目查询。保留尚未准备贴图的回退绘制路径。
- 保留 Canvas 2D、原有图片 Worker、动画分帧及空闲停帧。不增加模型、渲染库或远程依赖。

## 同环境对比

实际 Codex 内置浏览器、本地静态服务器；同一页对比冻结基线和改后代码。布局画布 1482×1120，宽画布 4096×1120；每场景预热 4 次后测量 12 次。以下为 JS 布局 / 绘制函数的中位耗时，不是 INP、整帧 GPU 耗时或真实手机测试。

| 场景 | 改前 | 改后 | 其他证据 |
|---|---:|---:|---|
| Vibe / Fiber 短文字布局 | 2.4 ms | 0.5 ms | 像素读取 6,639,360 → 496,824 字节，减少 92.5% |
| 宽画布短文字布局 | 6.2 ms | 0.8 ms | 18,350,080 → 371,228 字节，减少 98.0% |
| 约 770 字符长文本布局 | 15.7 ms | 9.9 ms | 字体测量 24,641 → 4,503 次 |
| 中文与空行布局 | 2.8 ms | 0.9 ms | 原有字形归属和成品像素相同 |
| 29,145 针的完整针织重绘 | 34.7 ms | 30.8 ms | 成品像素相同，日常 UI 保留分帧绘制 |
| 29,145 针的完整机织重绘 | 31.2 ms | 30.3 ms | 收益较小，不据此宣称帧率大幅提升 |

最初同代码基线多次运行波动明显，因此表中仅记录预热后的同页对比。像素读取量及测量次数是确定工作量；耗时会随系统负载、浏览器、字体和设备变化。

- 织入程度 0 / 25 / 100、针织和机织的暂停 / 完成、密集场景分帧成品、空闲停帧检查通过。
