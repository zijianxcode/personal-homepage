# Vibe Fiber 自定义颜色

2026-10-11。在纱线面板的「自定义颜色」中切换单色、多色。多色提供 2–8 个颜色，支持添加和移除；每行可用系统取色器或 HEX 输入（#RGB / #RRGGBB）。单色和多色分别保留设置，切换预设不会丢失自定义配色。浏览器本地存储 `vibe-fiber-yarn-v1` 保存当前模式、配色及选中预设；无效或不可用存储回到默认值。

颜色作用于文字、图案库、导入图片和针织 / 机织播放。多色沿用现有纱线分带算法；无效 HEX 保留上一次有效画面，失焦后恢复有效值。颜色输入按帧合并，更新复用针目布局和底布，只重绘受颜色影响的纱线层；材质缓存沿用 512 项 / 8 MiB 上限。手机端恢复布局入口移至顶部，避开颜色行。

## 验证

- `node --test tests/vibe-fiber/custom-colors.test.cjs`：4 项，检查颜色归一化、边界、颜色解析、文字 / 图片针目和光标改色。
- 本地预览打开 `tests/vibe-fiber/custom-colors-browser.html`，点击 Run color checks：25 项通过，覆盖单色、多色、增删和八色上限、九种表面、图片、针织和机织回放、布局与底布复用、保存恢复、预设切换及无效存储。测试结束会恢复之前的纱线设置。
- 源项目完整 Node 检查：23 项通过（包含之前图案提取与织造序列检查）。
- 内置浏览器检查 375、390、430、768、1440 宽度，颜色行均在视口内，无横向溢出。真实键盘 HEX 输入后取色器及文字颜色同步。
