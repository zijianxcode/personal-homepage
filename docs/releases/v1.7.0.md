# v1.7.0 · Visual Coding 扩展与安全加固

发布日期：2026-10-08（Asia/Shanghai）。

本版本汇总 v1.6.1 之后的主要变化，功能与安全措施已在主站上线。正式入口为 [bananabox.plus](https://bananabox.plus)，版本下载见 [GitHub Release](https://github.com/zijianxcode/personal-homepage/releases/tag/v1.7.0)。

## 主要变化

- Visual Coding 共七个项目，近期加入 Card Freeze、Effecter、Vibe Fiber、Far From Here 和 Grid Poster；作品倒序展示，独立体验页统一返回入口。
- Vibe Fiber 优化文字采样、字体测量缓存与针目贴图复用，保留原有成品和交互；[性能证据](../engineering/vibe-fiber-performance.md)。
- Far From Here 接入主域的场景与音乐学习体验；Grid Poster 接入网格海报编辑和 PNG / SVG 导出。
- 生产构建自动识别项目并添加官方域名校验，部分脚本压缩/混淆；[保护范围与边界](../engineering/visual-coding-copy-protection.md)。
- 六个 Things 课程页统一服务端许可校验，主域强制 HTTPS 与基础安全响应头；CI 和部署加入权限测试。
- 持续同步 Academy，保留根首页、研究所子目录和三层应急入口。

完整记录：[CHANGELOG.md](../../CHANGELOG.md)。

## 版本包

Release 附件：

- `personal-homepage-v1.7.0-production.zip`：完整生产静态快照，包含本机准备并已发布的大模型、WASM 与音乐片段。
- `SHA256SUMS.txt`：压缩包 SHA-256。
- GitHub 自动提供的 Source code：Git 跟踪文件的源码快照；其中不包含忽略的大模型/音频，需要沿用各项目资产准备流程。

生产 ZIP 内有一个 `personal-homepage-v1.7.0/` 顶层目录，静态首页直接在该目录内，附 `VERSION-PACK.md` 与 `release-manifest.json`。清单记录版本、Git 提交、保护版本及每个静态文件的体积和 SHA-256，用于恢复前核对快照。

生产静态包已经包含域名校验，应发布到既有正式域名及其现有子路径；本地开发使用 GitHub 源码快照。ZIP 不包含密钥、许可资源配置、私信数据库、云函数依赖、完整安全审计、node_modules、`.git` 或本地回滚文件。

## 恢复与维护

1. 下载 ZIP 和 SHA256SUMS，使用 `shasum -a 256 -c SHA256SUMS.txt` 校验。
2. 解压并核对 `release-manifest.json`；保持个人主页在 `/`、研究所在 `/academy/`。
3. 常规更新仍从仓库执行 `npm ci`、`CI=1 npm run deploy`，遵守 [稳定发布说明](../DEPLOYMENT-STABLE.md)。不要仅把 Academy 上传到根目录。
4. 云函数环境变量和数据库权限属于独立的服务端状态，静态 ZIP 无法恢复它们。生产资源配置应保留在 CloudBase，避免导出到公开附件。
5. CDN HTTPS 与响应头配置可用 `node scripts/harden-hosting-security.js --dry-run` 检查；本机回滚快照不属于公开版本包。

## 验证范围

权限测试、复制防护测试、课程入口与整站结构检查、完整部署产物校验、主站/Academy 线上验收均通过。七个项目完成入口和交互冒烟检查；六个许可资源返回内容与既有配置一致。

浏览器检查没有重新执行 Effecter 大模型推理，Far From Here 调度状态也不等同于设备实际出声。既有统计接口可用性、后端多实例限流和线上函数运行时维护等事项仍需后续处理，本版本不宣称消除全部风险。
